### 4.1 条码核心关键设计决策

1. **编码库选择**：内置实现而非引入 python-barcode 运行时依赖。理由：条码编码是纯确定性算法（码表 + 保护符 + 奇偶模式），内置实现可零依赖运行、可完整单测；同时用 python-barcode 做**开发期交叉验证**（已通过）。
2. **PNG 读写零依赖**：渲染与解码使用自实现的最小 PNG 编解码（zlib + 结构体），保证"渲染→扫描解码"往返测试在任何 Python 3.12+ 环境可执行；阶段 3 引入 Pillow/ReportLab 后扩展 SVG/PDF 导出。
3. **编号范围语义**：范围内的数字按**基础编号**（不含校验位）顺序分配，每个编码按格式规则**计算校验位**后落库——与 GS1 实际用法一致（公司前缀 + 物品参考号，校验位由规则计算）。
4. **并发安全**：每条线程独立 SQLite 连接 + `BEGIN IMMEDIATE` 写锁 + `busy_timeout=30s` + `barcode_value UNIQUE` 索引兜底；8 线程 × 10 次并发生成测试零重复。
