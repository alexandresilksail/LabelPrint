# CodeLabel Studio — 测试计划

## 1. 测试原则

- 每次修复后运行相关测试；每阶段结束运行完整套件
- 记录：命令、退出码、测试数、通过数、失败详情（存档 `docs/test_results_*.txt`）
- 跳过的测试不计为通过；失败必须修复或明确标记阻塞
- 旧测试与正确业务规则冲突时，修改测试并记录依据（在测试 docstring 注明）

## 2. 测试分层

### A. 单元测试（tests/unit/）
| 模块 | 覆盖点 |
|---|---|
| checkdigit | UPC-A/EAN-13/EAN-8 校验位计算与验证；非法字符/长度/前导零/空输入；独立测试向量 |
| encoder | 码表完整性；静区；三种格式模块串 |
| renderer/pngio/decoder | PNG 往返解码 == 原始数字 |
| service 来源校验 | 白名单；GS1 无授权编号拒绝；低层 DAO 绕过触发 IntegrityError |
| service 范围/状态 | 范围分配语义；状态流转；作废保留 |
| service 批量 | 上限/超限/0/负/布尔/取消/耗尽/并发 |
| database 迁移 | v1→v2 保数据；旧 import 映射；约束生效 |
| database 备份恢复 | 正常恢复；损坏文件拒绝；错误 schema 拒绝；版本不兼容拒绝；恢复前自动备份；恢复后完整性 |
| export | PDF 有效性（%PDF 头 + 页面尺寸）；SVG 结构；CSV 公式注入转义 |
| templates | 网格计算；越界警告；100% 尺寸 |
| licensing（服务端） | Ed25519 签名/验签/撤销/过期；宽限期逻辑 |

### B. 集成测试（tests/integration/）
- 注册→邮箱验证→试用开始（仅一次，重复请求幂等）
- 登录→退出；密码重置全流程
- 订单创建→人工确认→订阅激活→到期锁定
- 设备激活/解绑；授权撤销后重新验证
- 管理员操作→审计日志落库
- 数据库迁移 + 备份恢复集成

### C. 安全测试（tests/security/）
- 未登录访问受保护接口 → 401/403
- 普通用户访问管理员接口 → 403
- 伪造付款成功通知 → 拒绝
- 重复 webhook → 幂等（不重复发放）
- 过期授权 / 无效签名 / 撤销授权 → 拒绝
- 重复试用申请 → 拒绝
- 非法状态更新（跳过中间态）→ 拒绝
- 文件路径穿越（恢复/导入）→ 拒绝
- CSV 公式注入（`=cmd|...`）→ 转义
- 请求频率超限 → 429

### D. 端到端测试（tests/e2e/）
1. 新用户注册并完成邮箱验证
2. 登录并开始 7 天试用
3. 生成 UPC/EAN 编码
4. 导出 PDF/SVG/PNG/CSV
5. 打印预览（几何）
6. 试用结束受保护功能锁定
7. 仍可查看导出已有数据
8. 创建订阅订单
9. 管理员确认付款
10. 获得有效订阅授权
11. 管理员暂停/撤销授权
12. 客户端重新验证执行权限变更
13. 重装/升级后数据保留

## 3. 执行方式

```bash
# 全部测试
python -m pytest tests/ -v

# 分类
python -m pytest tests/unit tests/integration tests/security tests/e2e -v

# 结果存档
python -m pytest tests/ -v > docs/test_results_phase<N>.txt 2>&1
```
