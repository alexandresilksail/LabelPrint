# CodeLabel Studio — 安全检查清单

## 1. 密钥与敏感数据

- [x] 客户端不嵌入服务端数据库凭据、支付密钥、授权签名私钥（客户端仅持 Ed25519 公钥）
- [x] `.env` 不入 Git（.gitignore 已排除）；仅提交 `.env.example`
- [x] 管理员账号通过一次性初始化流程创建，不写死默认密码
- [x] 日志不记录密码、验证码、访问令牌、私钥（日志辅助模块统一脱敏）
- [ ] 部署者提供生产 SMTP / 支付凭据（见 DEPLOYMENT.md）

## 2. 认证与会话

- [x] Argon2id 密码哈希（argon2-cffi）
- [x] 邮箱验证/密码重置令牌：随机生成、有效期、一次性使用、库内仅存哈希
- [x] 短期访问令牌 + 可撤销服务端会话
- [x] 注册/登录/验证/重置接口速率限制
- [x] 登录失败锁定与账户枚举防护（统一错误响应）

## 3. 授权与业务规则

- [x] 授权判断必须经服务端；客户端不得相信未验证本地状态
- [x] 试用由服务端时间控制；重装/改本地时间/清本地库不重置
- [x] 同一账户初始试用唯一（DB 唯一约束 + 事务幂等）
- [x] GS1 授权来源必须带授权编号；禁止客户端参数伪造已授权状态
- [x] 本地去重 ≠ 全球唯一（界面提示文案见 UI）

## 4. 支付

- [x] 仅服务端确认付款后才开通订阅；前端提交"付款成功"无效
- [x] 人工确认流程记录操作人/时间/原因/审计日志
- [x] webhook 签名验证 + 幂等处理（payment_events 唯一约束）
- [x] 不存储完整银行卡号/CVV
- [x] 金额使用 Decimal，禁止浮点计算

## 5. 注入与文件安全

- [x] 全参数化 SQL（DAO 层无字符串拼接）
- [x] CSV 导出公式注入防护（`= + - @` 开头单元格加 `'` 前缀）
- [x] SVG 导出为本地生成内容，不接受不可信 SVG 输入
- [x] 备份恢复校验目标路径与文件头，拒绝无关数据库
- [x] 导入文件大小/行数限制，错误编码不静默保存

## 6. 服务端加固

- [x] 管理员接口服务端角色校验
- [x] 高风险操作二次确认 + 原因必填
- [x] HTTPS / HSTS / 安全头（部署文档与 nginx 配置）
- [x] CORS 白名单（不用 `*`）
- [x] 生产关闭调试模式与交互式文档

## 7. 扫描工具

- [x] bandit 静态扫描（结果存档 docs/test_results_security.txt）
- [x] pip-audit / safety 依赖漏洞检查
- [x] 人工审查清单（本文件逐项核对）

## 8. 已知限制（不声称"绝对安全"）

- 设备指纹为辅助风控信号，非身份验证唯一依据
- 人工付款确认依赖管理员尽职核实
- 未接真实支付前，自动支付相关验收标记为"待人工验证"
